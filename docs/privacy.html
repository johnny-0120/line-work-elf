LINE WORK ELF · PRIVACY

資料怎麼處理

更新日期：2026 年 10 月 24 日。本頁說明公開原始碼的資料流程，以及維護者以 Google Cloud 專案 LINE Work Elf 提供的個人日曆整合。自行部署者須依實際設定提供自己的告知。

讀取的資料與用途

小精靈接收傳給官方帳號的訊息，以及機器人已加入且啟用收集的工作對話，用於摘要、待辦與指令辨識。它無法讀取機器人未加入的對話或任意取得 LINE 歷史紀錄。選用 Obsidian 時，會搜尋設定的本機筆記庫。

Google Calendar 使用 calendar.events.owned 與 calendar.freebusy 權限，讀取擁有日曆中的活動資料、檢查空閒時間，並依使用者要求新增活動。Google 權限本身也包含變更與刪除活動的能力，但目前程式沒有提供這兩種操作。

傳到哪些服務

LINE 訊息由 LINE 與部署者的服務處理，AI 辨識所需的訊息、上下文，以及選用的相關筆記片段，會經 OpenRouter 傳送至模型供應者。免費模型不代表資料只留在本機；各服務的資料處理方式依其政策與實際設定而定。

Google API 請求送至 Google；日曆查詢結果目前由程式直接私訊擁有者的 LINE，模型只取得執行收據，不會取得該次查詢回傳的活動清單。使用者自行輸入的行程文字仍可能送 AI 解析。程式不會把憑證、日曆資料、對話或筆記上傳到公開 GitHub。

本機儲存與保留

OAuth 憑證、續期權杖與 SQLite 資料庫儲存在部署者的電腦。程式定期清理七天前的訊息與工作紀錄，待辦保留約三十天；備份、日誌及第三方服務的保留時間需由部署者另外管理。權杖會持續保留至撤銷或部署者移除。

停止收集與撤銷

群組可使用 /暫停收集 暫停，或 /停止收集 停止並刪除該來源的收集資料。私訊可用 /暫停私訊辨識；「私事」或 #private 開頭的文字會排除 AI 分析。未明確標記的內容須經 AI 判斷，請勿傳送不願交給外部服務處理的資料。

可隨時到 Google 帳戶的第三方連線 撤銷日曆權限。撤銷後程式不能再續期存取；已建立的 Google 活動不會因此刪除，本機已有紀錄也須另外清理。

Google 資料使用

本專案使用 Google 使用者資料僅為上述使用者功能，不出售資料，不用於廣告或訓練通用 AI 模型。Google API 資料的使用與轉移遵循 Google API Services User Data Policy，包括 Limited Use 要求。

公開原始碼與問題請至 GitHub Issues 聯絡；請勿在公開問題中附上日曆內容、對話、金鑰或權杖。個別部署資料的存取與刪除，請聯絡該部署者。
