資料怎麼處理

更新日期：2026 年 10 月 31 日。本頁說明公事小精靈服務的資料處理方式，以及維護者以 Google Cloud 專案 LINE Work Elf 提供的個人日曆整合。

讀取的資料與用途

小精靈接收傳給官方帳號的訊息，以及機器人已加入且啟用收集的工作對話，用於摘要、待辦與指令辨識。它無法讀取機器人未加入的對話或任意取得 LINE 歷史紀錄。選用 Obsidian 時，會搜尋部署者設定的本機筆記庫。

多人群組版需先私訊同意，再由取得代碼的本人在群中綁定，只收集綁定後的新文字。一般使用者的普通私訊預設不送 AI；另外同意開啟「智慧私訊助理」後，直接傳給小精靈的文字會送 AI 辨識，近期三輪上下文最多暫存一小時。可隨時暫停並清除暫存；不自動納入工作摘要。每人的訊息、來源、摘要及待辦使用獨立 SQLite 檔案，摘要只私訊該使用者；使用者不能使用部署者的 Obsidian 筆記或 Google Calendar，只能使用自己另行授權的日曆與保存的記錄。中央索引另存 LINE 使用者對應、加入時間、摘要排程、事件去重與用量計數。

獨立資料庫是程式與檔案的隔離，不是端對端加密，服務管理者仍能管理電腦上的檔案。摘要產生與送出前會向 LINE 核對群組身分；離群或停止收集會撤銷對應來源。

Google Calendar 使用 calendar.events.owned 與 calendar.freebusy 權限，讀取擁有日曆中的活動資料、檢查空閒時間，並依使用者要求新增活動。Google 權限本身也包含變更與刪除活動的能力，但目前程式沒有提供這兩種操作。

傳到哪些服務

LINE 訊息由 LINE 與部署者的服務處理，AI 辨識所需的訊息、上下文，以及選用的相關筆記片段，會經 OpenRouter 傳送至模型供應者。AI 分析不代表資料只留在本機；各服務的資料處理方式依其政策與實際設定而定。

Google API 請求送至 Google；日曆查詢結果目前由程式直接私訊擁有者的 LINE，模型只取得執行收據，不會取得該次查詢回傳的活動清單。使用者自行輸入的行程文字仍可能送 AI 解析。程式不會把憑證、日曆資料、對話或筆記上傳到公開 GitHub。

本機儲存與保留

OAuth 憑證、續期權杖與 SQLite 資料庫儲存在部署者的電腦。程式定期清理七天前的訊息與工作紀錄，待辦保留約三十天；備份、日誌及第三方服務的保留時間需由部署者另外管理。權杖會持續保留至撤銷或部署者移除。

停止收集與撤銷

群組可使用 /暫停收集 暫停，或 /停止收集 停止並刪除自己的該來源資料，不影響其他試用者。多人版另可私訊 /解除群組 完整名稱 移除自己的單一來源，或 /刪除我的資料 清除本機帳戶的綁定、訊息、摘要與待辦；短期防濫用計數仍保留約八天。備份最多保留七天，已送出的 LINE 訊息與外部服務紀錄不會因此撤回。

部署者自己的私訊可用 /暫停私訊辨識；「私事」或 #private 開頭的文字會排除 AI 分析。未明確標記的群組內容須經 AI 判斷，請勿傳送不願交給外部服務處理的資料。

可隨時到 Google 帳戶的第三方連線 撤銷日曆權限。撤銷後程式不能再續期存取；已建立的 Google 活動不會因此刪除，本機已有紀錄也須另外清理。

明確保存的筆記與手動對話

使用者按「記一則」或明確說「幫我記住」後，內容存於自己的 personal_notes 表，保留約三十天，不自動進公事摘要或日曆。按「整理雙人對話」後可連續轉傳或貼上文字，按「開始整理」才經 OpenRouter 送至模型服務；原文與分析暫存約二十四小時。只有本人按保存或加入待辦，才建立對應資料。已送出的訊息及備份仍依各自期限處理。目前不會直接解析聊天檔案、圖片或語音附件。

個人摘要網頁

完整摘要由服務端讀取各自的資料庫，不會上傳到 GitHub 或公開產品頁。LINE 按鈕發出十分鐘有效、只能交換一次的個人存取連結，持有連結者即可查看摘要與管理任務，請勿轉傳。瀏覽器以 Secure、HttpOnly Cookie 維持最長三十分鐘的存取工作階段；可以按「結束閱讀」撤銷這次存取。解除來源、撤回或刪除資料後，網頁下次更新會隱藏對應內容；已經閱讀、複製或截圖的內容無法收回。頁面沒有廣告追蹤或第三方分析腳本，不會把私密摘要公開索引。

自動任務建議與提醒

已綁定來源的新文字會分批經 OpenRouter 送至模型，產生附原文的任務建議。接受後才建立自己的任務；略過不執行，延後一天再顯示。期限與負責人可自行設定，負責人僅作紀錄。只有明確選定期限並開啟的任務才發送到期提醒；不自動新增日曆或替你傳訊。原文撤回或解除來源會使對應建議失效並清理任務；暫停來源會隱藏建議與原文搜尋，保留已接受任務。已送出的提醒無法收回。任務約保留三十天；未接受建議隨原文保留期限清理。

Google 資料使用

本專案使用 Google 使用者資料僅為上述使用者功能，不出售資料，不用於廣告或訓練通用 AI 模型。Google API 資料的使用與轉移遵循 Google API Services User Data Policy，包括 Limited Use 要求。

服務問題請至 GitHub Issues 聯絡；請勿在公開問題中附上日曆內容、對話、金鑰或權杖。個別部署資料的存取與刪除，請聯絡該部署者。

回首頁使用說明與條款

自選 Google Calendar 連線

使用者可另外授權自己的 Google Calendar，用於查詢及經確認後新增活動。Google 權限包含管理自己擁有的活動與查看空閒時間。每人的授權存於自己的本機 SQLite 空間；管理者仍能管理本機檔案，備份可能短期保留。授權不會加入群組摘要提示，其他使用者無法透過介面取得。

可在小精靈的日曆卡片解除本機連線，再到 Google 帳號的第三方連線撤銷授權。解除連線不刪除已建立的活動。請勿轉傳個人連線網址。
