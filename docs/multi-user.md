# 多人群組整理

大家可以加同一個 LINE 官方帳號，各自整理自己的工作群。受邀者不用準備 API key；AI 呼叫與 LINE 推播使用部署者的額度。多人模式只提供群組摘要與待辦，日曆、Obsidian 與一般私訊 Agent 仍為部署者專用。

## 試用者怎麼開始

1. 加機器人好友，傳 `/開始使用`，閱讀資料處理說明。
2. 同意後私訊 `/同意並開始`。機器人建立你的獨立空間，回傳一行 `/綁定群組 代碼`。
3. 邀請機器人加入你有權整理的工作群，先告知成員會使用外部 AI。由**取得代碼的本人**在十分鐘內貼上整行指令；其他人代貼無效。
4. 在同一群傳 `/工作群組 專題小組` 設定容易辨認的名稱，接著傳幾則新的工作討論。
5. 回到與機器人的私訊傳 `/整理`。完成後，摘要只會送給你，包含討論內容、原文明確的結論、尚待釐清與另標示的 AI 下一步建議。

只收集綁定後的新文字，不補讀歷史。群組中不需每句加「公事」。圖片、附件與語音不在目前的整理範圍。摘要與私事辨識可能出錯，請核對原文。

## 常用操作

| 操作 | 指令與效果 |
|---|---|
| 再加一個工作群 | 私訊 `/綁定群組`，本人將新代碼貼進該群；每人最多五群 |
| 查看自己的群組 | 私訊 `/群組` |
| 立即整理 | 私訊 `/整理`；只處理自己尚未整理的文字 |
| 每日摘要 | 私訊 `/每日整理 開啟`；台北時間 21:00 後，既有排程檢查後送出，有新文字且額度足夠才執行。預設關閉 |
| 關閉每日摘要 | 私訊 `/每日整理 關閉` |
| 查看待辦 | 私訊 `/待回覆`；完成後 `/已處理 編號`，只更新自己的待辦 |
| 查看額度與狀態 | 私訊 `/狀態`，AI 呼叫以 UTC 日期統計 |
| 暫停自己的收集 | 在已綁定群內傳 `/暫停收集`；原資料保留至清理期限 |
| 恢復自己的收集 | 在該群傳 `/工作群組 名稱`，從恢復後的新文字繼續 |
| 移除自己的群組 | 私訊 `/解除群組 完整名稱`，或在群內傳 `/停止收集`；清除自己的該群訊息與待辦 |
| 停止使用並清除帳戶 | 私訊 `/刪除我的資料`；不會刪其他使用者資料 |

群組同時有兩位使用者時，兩人須各自綁定。甲暫停、移除群組或刪除帳戶，不影響乙。若收到使用者離群事件，會撤銷該使用者的群組收集；產生摘要前與送出前也會向 LINE 核對成員身分，無法核對就暫緩。機器人離群則清除所有試用者的該群來源。

## 資料如何隔離

```text
同一個 LINE 官方帳號 → 簽章與接收帳號驗證 → 依本人身分分流
  部署者 → 原本的資料庫、筆記與日曆
  使用者甲 → members/<甲的不可逆索引>.sqlite3 → 只傳給甲
  使用者乙 → members/<乙的不可逆索引>.sqlite3 → 只傳給乙
```

每人的訊息、來源、摘要工作、待辦、重試與待送訊息使用各自的 SQLite 檔案。索引是以伺服器密鑰與 LINE 使用者 ID 計算的 HMAC；不要任意更換既有 `INTERNAL_TOKEN`。中央資料庫只另存使用者對應、同意時間、排程選項、事件去重與用量計數。

成員資料庫位於 `ELF_DB` 所在資料夾的 `members/` 子資料夾，沒有 Google 憑證或 Obsidian 設定。摘要輸入不讀其他人的資料庫，也不讀部署者的筆記。已撤回訊息、刪除資料或失去來源授權時，相關摘要工作會失效。

這是程式權限與資料檔案的隔離，**不是端對端加密**；管理電腦的人仍能管理本機檔案。私事或 `#private` 開頭先排除，其餘內容會送 OpenRouter 與模型供應者分析。訊息及摘要工作約保留七天，待辦約三十天。Windows 監督服務會分檔備份，最多保留七天；刪除目前帳戶不會撤回既有備份、第三方服務紀錄或已送出的 LINE 訊息。

## 部署者設定

完成原本的安裝後，在自己的 `.env` 加上：

```dotenv
PUBLIC_GROUPS_ENABLED=1
PUBLIC_MAX_USERS=50
PUBLIC_USER_DAILY_CALLS=30
PUBLIC_GLOBAL_DAILY_CALLS=900
```

依原有服務管理方式重啟 Elf；若更新了監督程式，也一併重啟監督服務。不要重新執行初次安裝或匯入腳本。既有 n8n 工作流與驗證憑證可沿用，內部 `/prepare`、`/deliver` 等端點仍須驗證，不能對外公開。

每位試用者預設每日最多三十次**實際模型請求**，相容重試與格式重試也計數，並非三十句聊天。訪客共用九百次上限；本程式所有呼叫另有九百五十次的每日保護上限，保留餘裕給部署者。其他程式共用相同 OpenRouter 帳號時，仍會競爭供應者額度。免費模型限制與 LINE 訊息配額分開計算；此設定不保證 LINE 推播或免費模型始終可用。

每人最多五個群組，近期每人最多收集一千則文字；過量的新文字會略過。只選工作群，避免大型閒聊群消耗儲存與推播額度。公開原始碼預設不啟用多人模式；維護者自己的部署可另外選擇開放試用。
