公事小精靈 · 使用教學

第一次使用，照這個順序就好。

先開通，再邀入群，接著綁定，最後用新訊息測試。雙人私聊另有貼上整理入口。

① 私訊開通→② 邀請入群→③ 綁定群組→④ 確認與測試
01 · 開通自己的空間

先加好友，在私訊裡開始。

  1. 加入「公事小精靈」為好友，LINE ID：@526byspu。
  2. 開啟和小精靈的一對一聊天室，按底部「開始使用」。想再看一次教學，可按首頁的「第一次使用：逐步教學」。
  3. 閱讀資料說明，按「同意並建立我的空間」。已有空間的人不必重建。
加入小精靈／開啟聊天

每個要收到摘要的人，都要用自己的 LINE 帳號各自開通。朋友開通，不會使用你的日曆或筆記。

02 · 先邀請，還不是綁定

把小精靈邀進要整理的群。

  1. 先取得群組成員同意，說明新文字會交給外部 AI 分析。
  2. 進入目標工作群 → 開啟群組選單 → 邀請 → 從好友選「公事小精靈」→ 確認。
  3. 確認成員列表裡有小精靈。成功加入後，群裡會出現歡迎卡片。

順序不能反過來：小精靈不在群內，就收不到你傳給那個群組的綁定訊息。傳出綁定要求，也不會自動把機器人邀入群。

03 · 兩種綁定方式，擇一即可

由你本人完成綁定。

方式 A：在群組歡迎卡片，按「同意並綁定這個群組」。

操作順序示意，非 LINE 截圖
小精靈已加入群組同意並綁定這個群組 ← 由你本人按收到綁定成功回應，再回小精靈私訊查看

方式 B：回小精靈私訊，按「綁定工作群」→「選擇群組並送出綁定」→ 在手機分享視窗選擇目標群組 → 確認送出。

方式 B 使用十分鐘有效的單次代碼，但不必手動輸入。電腦版無法使用手機跳轉時，可以按卡片的「電腦備用：複製指令」，再由本人貼進目標群。

04 · 看見狀態，才算成功

回私訊確認，再用新訊息測試。

  1. 按「我的群組」，確認是正確來源，而且狀態是「收集中」。名稱不易辨認時，點進去按「修改顯示名稱」。
  2. 到已綁定的群組傳一則新的工作訊息，例如「明天請確認活動文案」。
  3. 回小精靈私訊，按「立即整理」。按回覆卡片的「開啟我的摘要網頁」，進入後按更新查看完整結果；收到「開始整理」只是受理通知。

摘要只提供給你自己的空間。你可以在「我的群組」暫停、恢復或解除，不影響其他使用者。

只收綁定後的新文字，不補讀歷史紀錄。群組在綁定前說過的事情，不會自動出現在摘要。

LINE 電腦版不顯示底部圖文選單；手機可使用選單，電腦可使用私訊中收到的功能卡片。

05 · 整理雙人私聊

不改成群組，也能整理你提供的內容。

  1. 回小精靈首頁，按「整理雙人對話」。
  2. 去原本的雙人聊天室，選擇需要的訊息轉傳，或複製文字後貼給小精靈。可連續提供多則。
  3. 全部送完後，按「開始整理這些對話」。小精靈才會把這些內容一起送至 AI 服務。
  4. 開啟摘要網頁看討論重點與後續建議。想保存或建立待辦，回 LINE 首頁按「對話結果」，再按「保存這份整理」或「把建議加入我的待辦」。不會自動新增日曆或替你傳訊息。

每次最多三十段、合計一萬二千字。更長的紀錄請分批提供。分析暫存約二十四小時，明確保存的個人記錄約三十天。

另一個方式是在原聊天室「選單 → 設定 → 匯出聊天紀錄」取得文字檔，再開啟檔案、複製需要的段落。目前這版先支援貼上的文字，不會直接解析附件、圖片或語音。

官方 Messaging API 不能自動訂閱你和另一人的私人聊天室。貼上／轉傳是提供選定內容，與持續讀取原聊天室不同。

06 · 記住與執行是不同的事

讓小精靈知道你現在想做什麼。

你想做的事怎麼操作
單純保存資訊按「記一則」，或說「幫我記住……」。到「我的記錄」查看與刪除。
整理討論內容群組按「立即整理」；雙人私聊按「整理雙人對話」後提供文字。
處理待辦按「待回覆」，完成後逐項按「已處理」。對話分析的建議須先由你選擇加入待辦。
連接個人日曆「使用設定 → Google Calendar → 登入 Google 並連線」，每人授權自己的帳號。
新增行程日曆卡片按「新增行程」，輸入主題、選開始與結束時間，最後確認。以 Google 實際成功回應為準。

每位使用者都可以在「使用設定 → 智慧私訊助理」同意開啟自然聊天與自己的查詢工具。直接問「我的待辦有哪些」或「明天有什麼行程」即可；新增活動會進入確認介面。這不會讓小精靈讀取其他私人聊天室。沒有接入的 Gmail、Drive 或其他服務，不會假裝已操作。

目前免費，先看自己的用量。

「使用設定 → 我的方案」可查看功能與每日用量；目前不收費，也不要求信用卡。每日用量於台北時間早上八點重置，全站共用額度與 LINE 訊息配額也會影響服務。對話整理失敗時可按「重試這份整理」，不必重新貼上原文。每日自動摘要預設關閉，可在設定自行開啟，預設晚間九點後整理至網頁。結果預設不另外推播，想收到短提醒可在「使用設定 → 摘要網頁與通知」開啟。

完整摘要，改在網頁閱讀。

  1. 私訊首頁按「開啟我的摘要網頁」，或按「立即整理」後開啟回覆卡片中的入口。
  2. 在頁面按「進入我的摘要」。整理中會顯示狀態，每三十秒更新；也能自己按更新。
  3. 可搜尋文字、切換工作群組與貼上對話的摘要，旁邊查看待辦。
  4. 結束時按「結束閱讀」。保存對話、完成待辦與新增日曆，請回 LINE 操作。

個人連結十分鐘內只能開啟一次，進入後三十分鐘到期。持有連結即可閱讀，請勿轉傳或放在公開文章。看不到資料或連結過期時，回 LINE 重新取得；不要把個人連結貼到 GitHub。

閱讀與更新網頁不會重新分析、呼叫模型或發送推播。先看合成資料示範。

卡住時，先檢查這幾件事。

狀況先檢查
綁定沒有回應群內是否已有另一個官方帳號（LINE 同群最多一個）？小精靈是否已在那個群內？是否先在私訊開通？是否由你本人送出？分享視窗是否真的按了送出？
摘要沒有舊對話只收綁定後的新文字，請用新的測試訊息驗證。
網頁還沒看到摘要先按頁面更新，確認是否仍處理中；服務可能忙碌。貼上對話失敗可回 LINE 按「對話結果」重試。
日曆登入失敗重新取得個人連結，在同一個手機外部瀏覽器完成；連結十分鐘有效，不要轉傳。
看不到底部選單使用手機 LINE，重新開啟小精靈聊天室；LINE 電腦版不提供圖文選單。
