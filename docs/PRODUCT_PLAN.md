# 功能現況與後續規劃

更新：2026-10-27。現在是免費試用版，沒有收款、訂閱或自動續費。

## 已實作

| 需求 | 目前行為 |
| --- | --- |
| 第一次使用 | 加好友卡片、六步教學、開通同意、手機功能選單與電腦備用卡片 |
| 群組 | 先邀機器人、本人綁定，獨立來源列表；可改名、暫停、恢復、解除 |
| 多人隔離 | 每人獨立 SQLite；只讀自己的訊息、待辦、記錄與 Google 授權；中央索引負責路由與用量 |
| 討論整理 | 摘要討論重點、後續建議與待回覆，附原文依據；可自行開啟每日私訊摘要 |
| 雙人對話 | 轉傳或貼上文字、手動完成輸入後分析；失敗可直接重試；保存與加入待辦由使用者選擇 |
| 個人記錄 | 明確要求保存後記錄，可查看、刪除；不自動混入每日工作摘要 |
| 智慧私訊 | 每人另行同意開啟；聊天、選擇自己的查詢工具、新增日曆確認流程；暫停即取消尚未完成的私訊工作 |
| 日曆 | 每人網頁授權；查今天／明天／本週、新增活動確認、衝突檢查、解除連線 |
| 用量 | 個人與全站每日限制、方案卡片；目前只有免費方案 |
| 本機維運 | 排程監督程序、重啟恢復、健康檢查、備份與保留期限 |

## 這次修正

- 日曆空閒回應缺失／出錯時中止，不再當作可以排程。
- 權杖續期只更新同一份仍有效的授權，不能復活已解除或被替換的授權。
- 對話長度包含段落間換行，超限時保留既有輸入。
- 整理工作加入限時處理鎖，避免同一個待處理工作並行呼叫模型。
- 整理失敗可按鈕重試；撤回原文後不再發失效工作通知。
- 長筆記分段顯示，避免 LINE Flex 文字長度超限。
- 日曆連線入口讀取最新通道網址，避免服務重連後仍開啟舊網址。
- 一般使用者教學不再要求設定 AI 金鑰，開發者自行部署設定另外保留。

## 上線邊界與待驗收

離線測試涵蓋隔離、刪除／撤回競態、授權防護、用量與本次功能；實際 LINE 卡片格式及合成對話模型請求另由維護者驗證。這不等於已完成其他真人的手機授權與完整操作驗收。

只收機器人在場且綁定後的新文字；不能讀歷史訊息或其他雙人聊天室。目前不直接解析附件、語音、圖片。新增日曆必須由使用者確認，不會替人傳訊。Google 未驗證應用仍可能顯示警告、受使用者數量限制。

本機與外部通道在線、LINE 訊息配額、模型供應服務都會影響可用性。免費試用適合逐步邀請朋友，尚未承諾大規模商用可用性。正式擴大前先確認 LINE 訊息配額、固定服務網域、Google OAuth 驗證、異機備份復原與告警。

下一輪真人驗收：兩位朋友各自開通與授權、同群各自綁定、各自看到自己的待辦與日曆、其中一人解除仍不影響另一人；先以測試活動核對新增與重複送出行為。

## 金流之後怎麼接（尚未實作）

`service_plans.current_plan()` 是方案讀取邊界，現在無論輸入什麼都回傳免費版。付款入口、付費權限與金流 Webhook 均未啟用；目前不收取信用卡或帳單資料。

確定金流供應商後，再實作：伺服器驗證簽章的付款事件、唯一事件去重、訂單與訂閱狀態、退款／取消與到期處理、伺服器端方案權限、使用量帳本，以及付款前的價格與續訂告知。不能由 LINE 按鈕、回呼網址參數或模型回覆直接升級方案。先用供應商測試環境驗證付款成功、延遲、重送、取消與退款，再另外啟用正式收款。
