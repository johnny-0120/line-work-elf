LINE WORK ELF

群組聊完了，
下一步交給小精靈。

整理工作討論、找出待回覆、保存重要資訊，再把確認好的安排放進自己的日曆。朋友也能使用同一個小精靈，資料各自保存。

加入小精靈 第一次使用：圖文教學

從這四步開始

加好友並開通自己的空間 → 把小精靈邀入工作群 → 由本人按鈕綁定 → 傳新訊息後按「立即整理」。摘要只會私訊你，不會把別人的資料混進來。

除了列時間，還能整理事情的脈絡

查看討論重點、決定了什麼、可能需要回覆的事，以及接下來可以做什麼。雙人對話可以轉傳或貼上需要整理的文字，送完再按開始整理。

用說的，也能找到自己的工具

在「使用設定 → 智慧私訊助理」同意開啟後，可以聊天，或直接問「我的待辦有哪些」「明天有什麼行程」。要新增活動，會帶你確認主題與時間。重要資訊可以按「記一則」保存。

每個人的日曆，各自登入

「使用設定 → Google Calendar」登入自己的 Google 帳號，就能查詢與新增活動。查不到資料時會回報問題，不會假裝已完成。你可以隨時解除連線。

目前免費使用

不用購買方案或提供信用卡。每人最多綁定五個群組，AI 每日用量可到「使用設定 → 我的方案」查看。全站共用額度與 LINE 訊息配額可能影響服務。日後若推出付費方案，會另外公告並由你主動選擇；現在沒有收款流程。

只接收機器人已加入且綁定後的新文字，不能自動讀取其他私人聊天室。群組啟用前請告知成員；AI 分析會使用外部服務。這是試用服務，電腦連線與第三方服務仍會影響可用性。
