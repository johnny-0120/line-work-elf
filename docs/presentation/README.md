# 公事小精靈：10 頁圖文介紹

[下載可編輯 PowerPoint](https://github.com/johnny-0120/line-work-elf/releases/download/intro-2026-10-23-visual/line-work-elf-illustrated-10pages.pptx) · [使用教學](../usage.md) · [安裝說明](../../README.md#開始前)

本介紹說明工具用途、互動方式、資料範圍與目前驗證狀態。對話與摘要均為合成情境示範，並非真實聊天紀錄。簡報文字可編輯，背景為 AI 生成的裝飾圖像。

## 1. 群組聊完之後

指定工作群的交件期限、時間更動與待確認要求，由小精靈整理並私訊本人。你也能直接問它，使用自己的筆記與日曆工具。

![封面](slides/01.png)

## 2. 整理後保留原文依據

下圖是合成對話。AI 整理出期限與待確認事項，仍需要你回頭核對，不保證所有語意與責任人判斷都正確。

![對話與整理結果](slides/02.png)

## 3. 邀請並綁定群組

邀請自己的小精靈加入，私訊取得一次性綁定指令，貼進正確群組再依提示啟用。之後的新文字才會收集。

![群組來源綁定](slides/03.png)

## 4. 私訊直接講需求

工作、筆記問題與日曆要求會交給對應工具。資訊不足時先追問，私訊不必每次加「公事：」。

![自然語言私訊](slides/04.png)

## 5. 每日摘要與待回覆

21:00 排程與 `/整理` 產生摘要，`/待回覆` 查看事項，`/已處理 編號` 標記完成。它無法得知你是否已在其他地方回覆。

![摘要與待回覆](slides/05.png)

## 6. 明確安排與暫定想法

缺時間先追問，暫定安排先確認。查詢與空閒檢查已驗證，真實新增活動仍待補測。

![行程安排](slides/06.png)

## 7. 筆記補上你的背景

搜尋相關 Markdown 片段，回答附筆記名稱與原文。這是關鍵字檢索，不是完整讀取所有筆記與附件。

![筆記背景](slides/07.png)

## 8. Agent 的工具分工

n8n 處理摘要 AI Agent 與排程，Python 處理擁有者私訊、待辦、筆記與 Calendar 工具。操作結果依實際工具回傳。

![Agent 工具分工](slides/08.png)

## 9. 接收範圍與資料

不能讀全部 LINE、未加入群組與加入前歷史。資料庫在本機，需要分析的對話與筆記片段仍會送到模型供應方。

![資料與隱私](slides/09.png)

## 10. 開始使用小精靈

加入公事小精靈，依[圖文教學](../getting-started.html)開通、邀入群並綁定，即可整理新對話。現在免費試用；想自行架設的人，另見 GitHub README 的部署說明。下方圖片為較早版本的部署介紹。

![開源部署與驗證狀態](slides/10.png)
